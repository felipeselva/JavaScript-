# 📘 JavaScript e TypeScript - Full Stack

**Javascript e TypeScript - front-end e back-end (Full Stack)**  
Node, Express, noSQL, React, Hooks, Redux, Design Patterns

## 📚 Curso de JavaScript e TypeScript - Do Básico ao Avançado

Repositório com anotações, exercícios e projetos desenvolvidos durante o curso  
**"JavaScript e TypeScript do básico ao avançado"**.

O curso aborda de forma completa o ecossistema JS/TS, tanto no front-end quanto no back-end, com foco em desenvolvimento **full stack moderno**.

---

## 🚀 Tecnologias e conceitos abordados:

### ✅ Linguagens e Ferramentas

- JavaScript moderno (ES6+)
- TypeScript
- HTML5 & CSS3
- Webpack & Babel

### 🎨 Front-end

- React (Class Components & Functional Components)
- React Hooks
- Redux & Redux-Saga
- Next.js (SSR, SSG, ISR)
- localStorage

### 🖥️ Back-end

- Node.js
- Express
- MongoDB (com Mongoose)
- MySQL / MariaDB / PostgreSQL (com Sequelize)
- Strapi
- Knex.js (Query Builder)

### 🌐 APIs e Segurança

- APIs RESTful
- Autenticação com JWT e sessões
- Segurança em aplicações web
- Middlewares

### 🚀 Deploy e Infraestrutura

- NGINX (Proxy reverso)
- PM2 (Gerenciador de processos Node)
- Google Cloud Platform (GCP)
- Certificados SSL/TLS (Let's Encrypt)
- SSH, Git e versionamento
- Github Webhooks para CD

### 🧪 Qualidade de Código

- Testes automatizados com Jest
- Expressões regulares (Regex)
- EditorConfig, ESLint, Prettier
- Princípios SOLID
- Padrões de projeto (Design Patterns - GoF)
- Programação orientada a objetos (POO)
