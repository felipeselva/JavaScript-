Curso de JavaScript e TypeScript - Do Básico ao Avançado

Repositório com anotações, exercícios e projetos desenvolvidos durante o curso "JavaScript e TypeScript do básico ao avançado".
O curso aborda de forma completa o ecossistema JS/TS, tanto no front-end quanto no back-end, com foco em desenvolvimento full stack moderno.

🚀 Tecnologias e conceitos abordados:

JavaScript moderno (ES6+) e TypeScript

Front-end: HTML5, CSS3, Webpack, Babel, React (Hooks, Redux, Redux-Saga)

Back-end: Node.js, Express, MongoDB, Sequelize (MySQL/MariaDB), PostgreSQL

APIs RESTful com autenticação via JWT e sessões

Next.js + Strapi, SSR, SSG, ISR

Deploy com NGINX, PM2, GCP, SSL/TLS (Let's Encrypt)

Segurança em aplicações web

Testes automatizados com Jest

Padrões de projeto (Design Patterns - GoF)

Princípios SOLID e boas práticas de POO

Expressões regulares (Regex)

Query Builder (Knex.js)

CI/CD com Github Webhooks
